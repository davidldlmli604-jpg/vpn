## Android — этап 1: главный экран, ключ из буфера и по QR-коду, подключение

**Что готово.**
- Приложение для Android 8.0 и новее. Экраны, тексты, цвета и Шелти — те же, что у Windows-версии (общий код):
  поменяете оформление — поменяются обе. На телефоне разделы внизу, под большим пальцем; большая кнопка — посередине.
- Ключ добавляется двумя способами: «Вставить ключ» (из буфера обмена) и «Сканировать QR» (камерой).
- **Подписки** (добавлено раньше плана — у вас только подписка): ссылка на подписку вставляется той же кнопкой
  или QR-кодом, серверы из неё появляются во вкладке «Серверы», там же выбирается сервер; подписка обновляется
  сама по сроку поставщика и кнопкой «Обновить». Смена сервера во время работы VPN переподключает на новый.
  Проверка задержки серверов на телефоне — этап 3 (кнопки пока скрыты).
- Подключение — через системный VPN Android: весь трафик телефона идёт через сервер (переключателя режимов нет —
  он не нужен). При первом включении Android один раз спросит разрешение на VPN.
- Пока работает VPN, в шторке висит уведомление «VPN включён» с кнопкой «Выключить» (без него Android выключил бы VPN).
- На главной — задержка, скорость, время работы, сколько скачано и под какой страной вас видят сайты.
- Ключи хранятся зашифрованными ключом из защищённого хранилища Android; в резервные копии не попадают.
- Российские сайты (.ru, .рф, .su) уже идут напрямую; полные списки, приложения мимо VPN и свои списки — этап 2.
- Чего на телефоне пока нет (раздела нет совсем, а не пустые кнопки): проверка задержки и кнопка «Проверить, всё
  ли работает» (этап 3), «Мимо VPN» (этап 2), «Защита», плитка в шторке, автозапуск, мастер первого запуска (этап 4). Новый добавленный
  ключ сразу становится выбранным.

**Что нужно от вас один раз — пароль подписи.** Чтобы каждая новая версия вставала поверх старой (иначе пропадут
сохранённые ключи), все версии подписываются одним ключом. Сам ключ лежит в хранилище зашифрованным, а пароль к
нему нужно положить в «секреты» GitHub (его видят только сборки, в открытом хранилище он не появляется):
1. Откройте хранилище на GitHub → **Settings** → слева **Secrets and variables** → **Actions**.
2. **New repository secret**. Name: `ANDROID_KEYSTORE_PASSWORD`. Secret: пароль, который я прислал в чате.
3. **Add secret**. Затем Actions → «Сборка для Android» → **Run workflow** (или просто дождитесь следующей сборки).

Пароль сохраните у себя (например, в менеджере паролей): если его потерять, следующую версию придётся ставить
начисто, а значит, заново добавлять ключи. Пока секрета нет, сборка проходит, но APK получается неподписанным
(в имени «НЕ-ПОДПИСАН») — такой Android не установит.

**Как скачать и поставить APK.**
1. GitHub → Actions → «Сборка для Android» → последний запуск с зелёной галочкой → внизу Artifacts →
   `tropa-android-0.1.N` (это zip, внутри `tropa-0.1.N.apk`). Удобнее скачать на компьютер и перекинуть на
   телефон, или открыть ту же страницу в браузере телефона (нужно войти в GitHub).
2. На телефоне откройте файл `.apk`. Android попросит разрешить установку из этого источника (браузера или
   «Файлов») — разрешите. Play Защита может предупредить о «неизвестном приложении» — «Всё равно установить».
3. Новые версии ставятся так же, поверх старой: ключи и настройки остаются.

**Что я не смог проверить без настоящего телефона** (здесь нет ни Android, ни эмулятора — честно):
- что VPN реально поднимается и трафик идёт через сервер; что работают все типы ключей на телефоне;
- окно разрешения VPN, уведомление в шторке и кнопка «Выключить» в нём;
- сканер QR-кода и разрешение камеры;
- чтение ключа из буфера обмена; шифрование данных и их сохранность после обновления поверх;
- вид на разных экранах (проверял только в браузере с размером экрана телефона), вырезы и «чёлки»;
- поведение при смене Wi-Fi ↔ мобильный интернет, при входе в режим экономии батареи.
**Состояние сборки.** Сборка на GitHub зелёная: движок, приложение и APK собираются (запуск 4,
https://github.com/davidldlmli604-jpg/vpn/actions/runs/37472837714). Пока на GitHub нет секрета с паролем
подписи, APK выходит неподписанным (`tropa-0.1.N-НЕ-ПОДПИСАН.apk`) — после добавления секрета следующая сборка
даст подписанный `tropa-0.1.N.apk`, который ставится на телефон.

Что проверено: код приложения собирается на GitHub в APK, движок собирается из исходников sing-box 1.14.2,
настройки для телефона принимает сам sing-box (`sing-box check`, для каждого вида ключа — tests/config-check.test.ts),
Windows-версия после переноса общего кода проходит все свои тесты.

## Автообновление и плавность (после этапа 4)

**Что сделано.**
- Анимации больше не дёргаются: окно было перегружено размытием (около 13 кадров в секунду), теперь около 60.
  Подробности — РЕШЕНИЯ.md, раздел 28.
- Программа обновляется сама: проверяет новую версию при запуске и раз в 6 часов, скачивает в фоне и ставит,
  когда вы её закрываете. В «Настройках» → «Обновления» есть «Проверить сейчас» и «Обновить сейчас», а также
  переключатель «Обновлять автоматически». Ключи и настройки при обновлении сохраняются.

**Как получить первую версию с автообновлением.** Один раз вручную: GitHub → Actions → «Сборка для Windows» →
последний зелёный запуск → внизу файл `tropa-windows-0.2.N` (или сразу Releases → последняя версия →
`tropa-setup-0.2.N.exe`). Закрыть «Тропу» (значок возле часов → «Выйти»), запустить установщик — он встанет
поверх. Дальше новые версии придут сами.

**Если Chrome пишет «Заблокировано скачивание опасного файла».** Это из-за того, что у программы нет платной
цифровой подписи и Google её ещё «не знает». Откройте `chrome://downloads`, у файла нажмите «Скачать опасный
файл» / «Сохранить». Или скачайте через Edge. Нужно только для ручной установки.

**Что не проверено на настоящей Windows.** Сама установка обновления (скачивание с GitHub, тихая установка
поверх, перезапуск) — в этой среде нет Windows; проверены логика и тесты (tests/updater.test.ts) и то, что
сборка на GitHub выкладывает выпуск.

## Этап 1 — каркас, главный экран, вставка ключа, подключение в режиме прокси

### Что готово

- **Приложение запускается и работает** (Electron + React + TypeScript + Vite), название «Тропа» берётся из одного файла `brand.json`.
- **Главный экран**: одна большая кнопка с понятными состояниями — *Выключено / Подключаюсь / Работает / Ошибка* — и своей анимацией на каждое. Рядом: сервер и страна (с настоящим флагом), задержка, скорость, время работы, сколько скачано, **«Ваш адрес сейчас виден как: <страна>»**, живой график скорости.
- **«Вставить ключ»**: сам берёт ключ из буфера обмена и определяет тип. Понимает `vless` (в том числе Reality), `vmess`, `trojan`, `ss`, `hysteria2`, `tuic`, `anytls`, список ключей, готовый файл sing-box. Битый ключ — понятная фраза вместо технической ошибки.
- **Подключение в режиме «Только браузер и программы»** (системный прокси): включается и выключается, прокси в Windows прописывается и убирается сам.
- **Список серверов**: карточки с флагами, переименовать, удалить, «любимый» (звёздочка).
- **Ключи хранятся зашифрованными** средствами Windows; в журнал и на экран целиком не выводятся.
- **Три набора оформления** (Сияние, Закат, Хвоя), тёмная и светлая тема, три уровня анимации — выбираются в «Настройках». Анимаций много: переливающийся фон, частицы вокруг кнопки, вспышка при включении, «живые» числа, волна при смене темы, плавные переходы между страницами и т. д.
- **Шелти** 🐕 — по твоей просьбе. Собака внизу слева: следит за курсором, дремлет, радуется, когда всё работает, и **подсказывает простыми словами, что делает то, на что навели мышку**. Выключается в «Настройках».
- Автоматическое **переподключение при обрыве** и защита от «ложного подключено» (кнопка показывает «Работает» только когда через сервер реально прошёл запрос).

В коде уже лежат заготовки для следующих этапов (права администратора, аварийная блокировка интернета, загрузка подписок, обновление списков правил) — они написаны, но **к окну не подключены и считаются непроверенными**, пока не дойду до их этапа.

Остальное по плану ещё впереди и в окне помечено «скоро» (режим «Весь компьютер», «Мимо VPN», «Защита») или пока спрятано.

### Как это запустить на Windows

1. Поставь [Node.js 22 LTS](https://nodejs.org) (если ещё нет).
2. Открой папку проекта в терминале (PowerShell) и выполни по очереди:

   ```
   npm install
   npm run fetch:singbox -- --target win32-x64
   npm run build
   npm start
   ```

   Вторая команда скачивает официальный sing-box и **сверяет контрольную сумму**; если не совпадёт — ничего не установит.
3. Нажми **«Вставить ключ»** (предварительно скопировав ключ) и большую кнопку.

   Для разработки с автоматической перезагрузкой окна: `npm run dev`. Посмотреть только оформление в обычном браузере (с тестовыми данными): `npm run ui`.

Как проверить, что системный прокси работает: после подключения открой *Параметры Windows → Сеть и Интернет → Прокси* — там должен появиться `127.0.0.1:7890`; после отключения — пропасть.

### Что я проверил (и чем)

Всё ниже проверено на Linux с настоящим sing-box 1.14.2:

- **Разбор ключей** — 79 проверок: каждый тип (включая варианты: Reality, WebSocket, gRPC, старый и новый вид `ss`, перебор портов и т. д.), **40+ видов битых ключей** (нет адреса, порта, пароля, кривой UUID, неподдерживаемый транспорт…), мусор, подписки, чужой файл настроек.
- **Каждый собранный файл настроек прогоняется через `sing-box check`** (79 проверок: каждый тип ключа × оба режима × разные настройки) **плюс своя проверка ссылок внутри файла** — оказалось, что `sing-box check` не замечает ссылку на несуществующий выход или набор правил (это вылезло бы только при запуске).
- **Сквозной трафик через настоящий sing-box-сервер на localhost** для 14 вариантов (Shadowsocks, VLESS в разных обёртках, Reality+Vision, VMess, Trojan, Hysteria2, TUIC, AnyTLS): ключ → наш код → файл настроек → реальный запрос дошёл.
- **Правила маршрутов вживую**: российские зоны напрямую, Яндекс/VK по спискам, заблокированные СМИ через VPN, домашняя сеть, свои списки, программа мимо VPN, российские IP.
- **Режим «Весь компьютер»** — реальный перехват трафика устройством TUN на Linux (на трёх сетевых стеках) — только на тестовую подсеть, остальное не затрагивалось.
- **Жизненный цикл подключения**: подключение, скорость, ошибка при неверном ключе, обрыв и автопереподключение, отмена во время переподключения, нет прав, нет движка, битый список правил.
- **Хранилище**: в файле на диске нет ни паролей, ни идентификаторов; повреждённый файл не роняет программу.
- **Настоящее приложение** в Electron (под виртуальным экраном): 13 сценариев — вставка из буфера, подключение, трафик, отключение, шифрование на диске, перезапуск, неверный ключ, мусор в буфере, подсказки Шелти.

Итого: **206 проверок + 13 сценариев настоящего окна, все зелёные** (`npm test`, `npm run test:e2e`).

### Чего я НЕ мог проверить (честно)

- ⚠️ **Нигде не запускал на настоящей Windows.** Всё, что касается Windows, написано по документации, но не проверено: запись системного прокси в реестр и его восстановление, шифрование ключей (DPAPI), уведомления, вид заголовка окна с кнопками Windows.

## Этап 2 — туннель («Весь компьютер»), российские сайты напрямую, программы мимо VPN

### Что готово

- **Режим «Весь компьютер»** (туннель): переключатель на главной экране теперь рабочий. Нужны права администратора — программа **один раз** объясняет зачем (окно с понятным текстом), Windows спрашивает «Разрешить?», дальше всё запускается без вопросов. Если отказать — ничего не ломается. Забрать разрешение можно в «Настройках».
- **Страница «Мимо VPN»**:
  - «Российские сайты открывать напрямую» (включено по умолчанию): зоны `.ru`, `.рф`, `.su` и готовые списки (Яндекс, VK, Госуслуги, банки, магазины, российские IP-адреса и др.). **Заблокированные в России СМИ при этом всегда идут через VPN**, даже если у них домен `.ru`. Списки обновляются сами раз в 3 дня; кнопка «Обновить сейчас».
  - **Программы мимо VPN**: выбор из запущенных и из установленных (с иконками и поиском) + готовый набор **«Игры и лаунчеры»** (62 программы: Steam, Epic, Battle.net, Riot, EA, Ubisoft, GOG, Wargaming/Lesta, VK Play и популярные игры).
  - **Свои списки сайтов**: «всегда через VPN» и «всегда напрямую». Понимают адрес целиком (`https://www.сайт.рф/страница`), звёздочку (`*.site.ru`), кириллицу и IP-адреса/сети; то, что не поняли, подсказывают.
  - **Домашняя сеть** (роутер, принтер, телевизор) — всегда напрямую, это включено навсегда.
- Любая смена этих настроек при включённом VPN **сама перезапускает подключение** (без лишних уведомлений) и показывает «Настройки применены».
- **Защита от аварий**: программа теперь при любом выходе останавливает движок и возвращает системный прокси, а при следующем запуске убирает «хвосты» после аварийного завершения (подробности — РЕШЕНИЯ.md, раздел 15). Это нашлось тестами — до этого при «неправильном» выходе мог остаться забытый движок и пропасть интернет.
- Единственная копия программы теперь работает и между обычной копией и копией с правами администратора.

Окно «Весь компьютер» теперь затемняет всё, а Шелти подсказывает и на новых экранах.

### Как это запустить

Так же, как на этапе 1 (`npm install`, `npm run fetch:singbox -- --target win32-x64`, `npm run build`, `npm start`). Чтобы попробовать туннель: на главной экране выбери «Весь компьютер» → «Разрешить».

Как проверить, что туннель работает: на главной после подключения «Ваш адрес сейчас виден как…» покажет страну сервера; в «Параметрах Windows» прокси при этом не прописывается; игры и программы без поддержки прокси идут через VPN.

### Что я проверил (и чем)

На Linux с настоящим sing-box:
- **Правила в настоящем окне**: через интерфейс выбрана программа, включён набор игр, вписаны свои списки (с кириллицей) → прочитан **реальный файл настроек, который получил движок**: правила в правильном порядке («всегда через VPN» раньше зоны `.ru`, домашняя сеть напрямую, программы напрямую, все 31 набор списков), выключение «Российские сайты напрямую» перезапустило подключение уже без списков, и трафик продолжил идти.
- **Закрытие при включённом VPN**: быстро, движок остановлен, файл с секретами удалён.
- **Права администратора** (31 проверка, вместе с авариями): задача планировщика (XML, команды), согласие/отказ/повторный запуск, перезапуск с правами, отзыв, «замок единственной копии», список программ.
- **После аварии**: забытый настоящий процесс движка находится и останавливается; чужой процесс — нет; прокси после аварии возвращается.

### Чего я НЕ мог проверить (честно)

## Этап 3 — подписки, список серверов, задержка, QR-код, кнопка «Проверить»

### Что готово

- **Подписки.** Ссылку на подписку (то, что присылает поставщик) вставляешь той же кнопкой «Вставить ключ или подписку» (или просто Ctrl+V в окне). Появляется карточка подписки: название от поставщика, сколько серверов, когда обновлена, **полоска «использовано 134 ГБ из 200 ГБ · действует до …»**. Подписка обновляется **сама** (по сроку, который задал поставщик, обычно раз в 12 часов), а кнопкой со стрелочкой — сразу. Если сайт подписки не отвечает, у карточки появляется понятная пометка, а серверы **остаются** (временный сбой не оставит тебя без списка).
  - При обновлении **сохраняется всё, что ты настроил**: своё название сервера, «звёздочка», выбранный сервер — даже если поставщик сменил у сервера ключи. Сервер, который ты удалил из подписки, назад не возвращается.
  - Адрес подписки (в нём обычно секретный токен) хранится зашифрованным и на экране не показывается.
- **Список серверов с проверкой задержки.** Кнопка «Проверить задержку» (все серверы), молния на карточке (один сервер), при первом заходе на страницу — **само**. Рядом с каждым сервером число в миллисекундах (зелёное/жёлтое/красное) или «не отвечает». Порядок «Как добавлены» / «Быстрые сверху» (любимые всегда сверху). На каждой карточке видно, из какой она подписки.
- **QR-код** ключа сервера и адреса подписки — в меню «…»: сначала предупреждение («в коде ваш ключ целиком, показывайте только тем, кому доверяете»), код — по кнопке, сам прячется через полторы минуты.
- **Кнопка «Проверить, всё ли работает»** на главной (когда VPN включён): четыре шага по очереди с анимацией — связь с сервером, ваш адрес в интернете, поиск адресов сайтов (DNS: не видит ли провайдер, какие сайты открываешь), российские сайты напрямую (по данным самого движка, а не «открылся ли сайт»). В конце итог словами: «Всё работает…» / «В целом работает, но есть замечание…» / «Есть проблема…» с советом, что делать.
- Шелти знает про новые кнопки и подсказывает при наведении.

### Как это запустить

Так же, как раньше. Чтобы попробовать подписки: скопируй ссылку на подписку → вкладка «Серверы» → «Вставить ключ или подписку». Проверка — на главной после включения VPN.

### Что я проверил (и чем)

На Linux с настоящим sing-box (**286 проверок + 27 сценариев настоящего окна, все зелёные**; полный прогон повторён 6 раз подряд без сбоев):
- **Задержка на настоящем движке**: рабочий сервер получает миллисекунды, мёртвый — «нет ответа» в срок, битый ключ — «ключ не подходит» **и не мешает остальным**; 14 серверов за раз, результаты не перепутаны; прерывание во время проверки (в том числе при закрытии программы) — временный движок останавливается, файл с секретами удалён.
- **Подписки**: сверка списка (новые, исчезнувшие, смена ключей у того же сервера, переименование поставщиком, повторы, ручной сервер, удалённый человеком); настоящая загрузка по http с локального сервера (заголовки трафика/срока/названия/периода, перенаправление, ошибки 403/404/«страница входа»/Clash/пустая/сайт недоступен); срок обновления; тихое фоновое обновление; сбой не стирает серверы; **токен подписки не найден ни в состоянии окна, ни в файле данных, ни в журнале**.
- **QR**: картинка строится, разные ключи — разные картинки, сервер без исходной ссылки — честный отказ, слишком длинный ключ — понятное сообщение; в журнал содержимое не попадает.
- **Кнопка проверки**: все ветки логики на подставных ответах (хорошо, сервер молчит, медленный, адрес не изменился, адрес из России, DNS у провайдера, российский сайт через VPN, настройка выключена, отмена) **и** на настоящем движке: DNS-ответ движка прочитан, а «напрямую или через VPN» взято из списка соединений самого движка (российский сайт — `direct`, иностранный — `proxy`).
- **Настоящее окно (Electron)**: ссылка на подписку из буфера → карточка с полоской трафика и серверами; задержки (два сервера в миллисекундах, два «не отвечает»); «Быстрые сверху»; QR (предупреждение → код → закрыть → кода нет); обновление подписки добавило сервер, ошибка сайта показала пометку и серверы остались; кнопка проверки прошла 4 шага и показала итог; удаление подписки убрало её серверы; **Ctrl+V** настоящим нажатием клавиш добавил ключ (а в поле ввода на странице «Мимо VPN» вставка осталась обычной).

### Чего я НЕ мог проверить (честно)

- ⚠️ **Настоящую подписку поставщика**: проверял на своём локальном сервере, который отдаёт такие же заголовки и тело (список ключей в base64). Поставщики бывают с причудами — если какая-то подписка не читается, пришли ссылку (без токена, только название сайта) и текст ошибки.
- ⚠️ **Шаги проверки, которым нужен интернет** (страна адреса, чей DNS искал адрес, `ya.ru`): сеть в моей среде закрыта, поэтому на «живом» интернете они не запускались. Проверены: вся логика на подставных ответах, а те части, что решает сам движок (DNS-ответ, direct/proxy), — на настоящем движке. В настоящем окне при недоступности служб эти шаги честно заканчиваются «замечанием» — это видно в тесте.
- ⚠️ **QR-код не сканировал телефоном** (у меня нет камеры): проверено, что картинка строится правильно и однозначно; что именно считает твой телефон или приложение — нет. Код строится популярной библиотекой, но «пощупать» надо тебе.
- ⚠️ **Windows**: проверка задержки запускает временный движок (порты, процесс) — логика та же, что у обычного подключения, но на Windows не запускалась. Всё, что в этапах 1–2 было про Windows, по-прежнему не проверено на настоящей Windows (см. выше).
- Страна у серверов определяется **по названию** (если в названии нет «Германия»/«NL» и т. п., на карточке будет значок «страна неизвестна»). Настоящая страна выхода видна на главном экране после подключения.

### Что не получилось / ограничения
